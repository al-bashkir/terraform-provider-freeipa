# freeipa_dns_forward_zone (Resource)

FreeIPA DNS forward zone resource. Manages per-zone forwarders, forward policy, and enable/disable state.


## Example Usage

```terraform
resource "freeipa_dns_forward_zone" "internal" {
  zone_name          = "internal.example.lan"
  forwarders         = ["10.0.0.10", "10.0.0.11 port 5353"]
  forward_policy     = "only"
  disable_zone       = false
  skip_overlap_check = true
}
```



## Import Usage

```terraform
# The import id is the undotted zone FQDN.

import {
  to = freeipa_dns_forward_zone.internal
  id = "internal.example.lan"
}

resource "freeipa_dns_forward_zone" "internal" {
  zone_name  = "internal.example.lan"
  forwarders = ["10.0.0.10"]
}
```

## Schema

### Required

- `forwarders` (Set of String) Per-zone forwarders. A custom port can be specified using a standard format `IP_ADDRESS port PORT`.
- `zone_name` (String) Forward zone name (FQDN).

### Optional

- `disable_zone` (Boolean) Disable the forward zone (inverse of FreeIPA `idnszoneactive`). Defaults to `false`.
- `forward_policy` (String) Per-zone conditional forwarding policy. One of `only`, `first`, `none`. Defaults to `first`.
- `skip_overlap_check` (Boolean) Force creation even if the zone overlaps with an existing zone. Create-time only; ignored on update. Defaults to `false`.

### Read-Only

- `computed_zone_name` (String) Canonical zone name returned by FreeIPA (with trailing dot).
- `id` (String) ID of the resource (canonical zone name with trailing dot).
